## Security boundary

This repository is public. Therefore this branch MUST NOT contain:

- exact COM/MOT/SELF/LIFE/RPE candidate wording;
- protected Founder Alpha corpus payloads;
- participant response data;
- Founder feedback data;
- response values in operational telemetry;
- generated personal reports.

The scaffold loads an exact corpus from a **local file selected by the authorised operator**. The protected corpus remains outside GitHub. No network upload is required by the scaffold. The local browser storage used by the scaffold is not encryption; the Alpha run must therefore be executed only on a controlled device/profile.

## Runtime namespaces

- response data: `p120_founder_alpha_ru_v1`
- Founder feedback: `p120_founder_alpha_feedback_ru_v1`
- runtime log: `p120_founder_alpha_runtime_log_ru_v1`
- source manifest: `p120_founder_alpha_source_manifest_ru_v1`

## Fail-closed rules

The runtime refuses to start unless the local corpus:

1. declares `schema = p120.fa01.corpus.v1`;
2. declares locale `ru`;
3. includes a source manifest;
4. matches the manifest item count;
5. matches the manifest SHA-256 when `payload_sha256` is supplied; the hash authority is `SHA-256(JSON.stringify({modules,items}))` after parsing;
6. contains only supported response models;
7. contains unique item IDs;
8. does not declare respondent-facing candidate scoring.

An already-started Alpha session is fail-closed against a different corpus ID, version or verified payload hash. Export evidence and clear the local Alpha session before switching corpora.

## Report boundary

No integrated personal PDF is generated by this scaffold. Report cutover remains HOLD until authorised deterministic scoring parity and report-governance QA are complete.

## Run mode

Preferred Alpha mode is local/offline:

1. check out this branch;
2. open `founder-alpha/runtime/alpha-shell.html` from a controlled local environment or a local static server;
3. choose the protected corpus JSON from local storage;
4. complete the run;
5. export response, feedback, runtime-log and source-manifest files separately;
6. clear the local Alpha session after evidence capture.

Do not merge this branch into `main` before the Founder Alpha QA gate explicitly authorises it.
