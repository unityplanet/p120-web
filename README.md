# P-120 Web

Public website repository for the P-120 research project.

## Current public release

**P-120 Web Editorial v1.6.1 — Contrast Architecture Restoration**

GitHub Pages staging URL: `https://unityplanet.github.io/p120-web/`

v1.6.1 is a narrow corrective pass over v1.6.0. It restores stronger contrast architecture for semantic/scientific blocks while preserving the v1.6 HD/UHD stage system, mobile UX, typography, header and frozen measurement/scoring logic.

Historical release tags: `v1.5.0`, `v1.6.0`, `v1.6.1`.

This repository contains public website code and public-facing assets only. Do not commit authoritative scoring keys, technical keys, controlled research documentation, respondent or personal data, credentials, API keys, `.env` files, or other non-public P-120 materials.
