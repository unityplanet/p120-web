# P-120 Web

Public website repository for the P-120 research project.

## Current public release

**P-120 Web Editorial v1.5.0 — Unified Editorial Grammar**

GitHub Pages staging URL: `https://unityplanet.github.io/p120-web/`

## Deployment

GitHub Pages publishes from the `main` branch and repository root. The live website is represented by the current state of `main`.

Release history is maintained in [`CHANGELOG.md`](CHANGELOG.md).

## Public-repository boundary

This repository is only for public website code and public-facing assets.

Do **not** commit authoritative scoring keys, technical keys, controlled research documentation, respondent data, personal data, credentials, API keys, `.env` files, or other non-public P-120 materials.

The production scoring/report backend will be separated from this public frontend when introduced.
