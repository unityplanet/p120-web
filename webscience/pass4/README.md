## Scientific positioning / evidence domains

PASS 4 explicitly separates:

1. **E0 External scientific foundation** — published literature, empirical studies, existing constructs and measurement precedents.
2. **E1 P-120 internal architecture verification** — construct-boundary, ownership, redundancy, item-level, information-gain, scope/exposure, safety/privacy, computational-contract and cross-module verification.
3. **E2 Human/cognitive/cross-check evidence** — observations actually collected and adjudicated.
4. **E3 Psychometric validation** — respondent-sample quantitative validation evidence.
5. **E4 External replication** — separately established replication evidence.

Internal scientific-methodological, computational and cross-module verification is a real evidence class within the P-120 development record, but it is **not** empirical psychometric validation on respondent samples.

It does **not** contain completed post-EXT-SYS-PASS4 human cross-check evidence sufficient to claim demonstrated system synergy.

- empirical cross-layer discriminant validity — **NOT ESTABLISHED**;
- empirical incremental validity — **NOT ESTABLISHED**;
- validated cross-layer synergy — **NOT AUTHORIZED**;
- join-after-measurement / source-score independence — **REQUIRED**.
