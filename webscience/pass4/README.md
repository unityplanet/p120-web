## Scientific positioning / evidence domains

PASS 4 explicitly separates:

1. **External scientific foundation (E0)** — published literature, empirical studies, existing constructs and measurement precedents.
2. **P-120 internal architecture verification (E1)** — construct-boundary, ownership, redundancy, item-level, information-gain, scope/exposure, safety/privacy, computational-contract and cross-module verification.
3. **Human/cognitive/cross-check evidence (E2)** — evidence-bearing observations actually collected and adjudicated.
4. **Psychometric validation (E3)** — respondent-sample quantitative validation evidence.
5. **External replication (E4)** — separately established replication evidence.

Internal scientific-methodological, computational and cross-module verification is a real evidence class within the P-120 development record, but it is **not** empirical psychometric validation on respondent samples.
